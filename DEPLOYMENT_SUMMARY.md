## Deployment Steps

### Quick Deploy

```powershell
# 1. Build and publish
.\deploy-windows.ps1

# 2. Install services (as Administrator)
cd publish
.\install-services.ps1

# 3. Start services
.\start-services.ps1

# 4. Access application
# Web UI: http://localhost:5080
# API: http://localhost:5001
# Swagger: http://localhost:5001/swagger
```
